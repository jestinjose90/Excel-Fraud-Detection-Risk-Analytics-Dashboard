# Bank Fraud Detection & Risk Analytics Dashboard

## Project Overview
This project analyzes financial transactions to identify fraudulent activity and explore transaction risk patterns using Excel.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Charts and Visualizations
- Conditional Formatting
- Excel Formulas

## Project Tasks
- Analyzed transaction data to identify fraud patterns.
- Created KPIs to track total transactions, fraudulent transactions, and fraud percentage.
- Developed a risk-scoring approach using transaction details and account balance discrepancies.
- Built an interactive dashboard to explore fraud trends by transaction type, amount, and time.

## Key Features
- Fraud transaction analysis
- Transaction risk assessment
- Interactive dashboard
- KPI reporting and visualizations

## Disclaimer
This project is for educational and analytical purposes only. The risk-scoring approach is a project-level analysis and is not a production fraud detection system.
